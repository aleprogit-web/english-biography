# Stephen King - English Course Project

A simple webpage about **Stephen King**, created as part of my English course at **Fisk**.

This project was developed mainly to practice and improve my **HTML and CSS skills**, while also working with English content.

## 📚 About the Project

The website presents some information about Stephen King's life and career, including:

- Introduction
- Career
- Music
- The 1999 Accident
- Key Facts
- Quotes
- References

The project focuses on creating a structured and visually organized webpage using front-end technologies.

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome
- Google Fonts

## 🎯 Purpose

This project was created for my **English course at Fisk** and also serves as an opportunity to practice web development skills.

Through this project, I practiced:

- Semantic HTML
- CSS Grid
- Flexbox
- Custom fonts
- Layout organization
- Colors and visual design
- Spacing and positioning
- Working with external resources
- Creating a structured webpage

## 📖 About the Topic

Stephen King is an American author known for his novels, short stories, and works in the horror and fiction genres.

The website presents some information about his life, career, music interests, and the accident he experienced in 1999.

The information used in the project was researched from external sources, which are listed in the **References** section of the website.

## 🎓 Academic Project

This is a **practice project for my English course at Fisk**, created with the additional goal of developing my web development skills.

The website was created for educational purposes and is not intended to be a commercial website.

## 🌐 Project Focus

The main focus of this project was combining **English language practice** with **web development practice**.

It allowed me to work with English text while applying concepts I have been learning in **HTML and CSS**.
